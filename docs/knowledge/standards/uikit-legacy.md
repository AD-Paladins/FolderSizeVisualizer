# UIKit Legacy Standards

## N/A — macOS Application

This project is a **pure SwiftUI macOS application** with no UIKit dependency. UIKit is not imported, not referenced, and not used anywhere in the codebase.

All legacy bridging concerns are AppKit-related, not UIKit. See `../architecture/swiftui-uikit-bridge.md` for AppKit rules.
