# Architecture Decision Records

This directory records significant architectural decisions for this project.

## How to Add an ADR

1. Create a new file `../decisions/ADR-<NNN>-<short-title>.md`
2. Use the template below
3. Add an entry to this index

## Template

```markdown
# ADR-<NNN>: <Title>

**Date:** YYYY-MM-DD  
**Status:** Accepted | Proposed | Superseded by ADR-<MMM>

## Context
What is the problem or decision that needs to be made?

## Decision
What was decided and why?

## Consequences
What tradeoffs or implications does this decision have?
```
